Let's Be Guided

Save a comp's guides and bring them into any other comp — scaled to fit if the size is different.

Get Let's Be Guided Get it with Baerista

Free — name your price if you'd like to support it.

What it does

Export the guides from a comp into a small file next to your project, rename it, and import it into other comps, merging with or replacing what's there. Guides made at one size can be scaled to another.

How it works

  1. Open a comp with guides and click Export.
  2. Open another comp and pick the guide file.
  3. Import — merge or overwrite, scaled if needed.

Details

  • Merge or overwriteAdd to existing guides or replace them.
  • Scale to fit1920×1080 guides onto a square comp, for example.
  • Named presetsRename guide files to keep them straight.
  • Tidy upClear guide files or a comp's guides in one click.

Install

Version1.1.2
TypeDockable script
NeedsAfter Effects CC 2019 or newer
PriceName your price, from free

Easiest: install it from Baerista. On its own: copy the .jsx into After Effects' Scripts/ScriptUI Panels folder, restart, and open it from the Window menu. For update checks, turn on Preferences › Scripting & Expressions › Allow Scripts to Write Files and Access Network.

How feedback works

There are three review points: the direction, the first cut and the final. Each one includes two rounds of revisions. A round is one set of combined notes, so it helps to gather everyone’s thoughts into a single message.

Changing something that’s already approved, like the script after the direction stage, counts as new work. I’ll always tell you what it costs and how it moves the dates before I start on it.
